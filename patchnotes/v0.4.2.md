# MapCraft Update

## Models

- **New Feature:** Editable Children: right click a prop to list its model's meshes, then move, rotate, scale, hide or set collision on each one.
- Hidden meshes are left out of drawing and collision in Godot, along with every mesh under them.
- Add Model and dropped models go into the SDK's shared custom folder, so every map can reuse them.
- File > Import > glTF is gone; drop a .gltf on the window or use Add Model instead.

## Materials

- **New Feature:** Packed ORM pictures split into roughness and metallic when adding a material.
- Add Material puts new materials in the SDK's shared custom folder instead of beside each map.
- Heightmap pictures land in the Height slot instead of taking over Albedo.
- Dragging normal strength, roughness, metallic and height scale in the Material inspector updates smoothly without the views flashing purple.

## Surf Ramp

- Skip hidden faces no longer puts tools/skip on the ramp's bottom.

## Other

- Brush Type and Create Brush Entity are one right click menu.
- The website shows a Release notes link and how long ago the latest release came out.
