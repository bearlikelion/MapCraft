# MapCraft Update

## Shaders

- **New Feature:** Embedded Godot shaders: the World can carry a sky shader and each brush a spatial shader, saved inside the map with full undo.
- **New Feature:** Shader Editor workspace with Viewport, Material, Shader Graph and Script tabs that replace the central view.
- **New Feature:** Shaders panel (Ctrl+7) lists every shaded node, highlights the one being edited and shows compile errors in red.
- **New Feature:** Shader Parameters in the inspector, with sliders, color pickers, material slots and per value revert buttons, grouped like Godot's inspector.
- **New Feature:** Shader graphs with movable nodes and visible connections that generate Godot shader source.
- **New Feature:** PBR material authoring in the Material tab.
- Script tab adds Godot shader syntax highlighting, line numbers and compile errors with their line.
- Import and Export .gdshader swap a shader with a file.
- Embedded shaders draw live in the 3D views and animate, including sky shaders, screen texture refraction and half and quarter resolution passes.
- Quitting with unsaved shader work offers Save, Discard or Cancel.

## Lighting and Environment

- Lit view previews Godot's environment: procedural sky curves and energy, hemispherical ambient, distance fog with sun scatter, tonemapping and brightness, contrast and saturation adjustments.
- Unsupported tonemappers warn and fall back to filmic instead of drawing wrong.

## Assets and Packs

- **New Feature:** Add Material and Add Model copy your own pictures and models beside the saved map so they load like any custom asset.
- **New Feature:** Export Custom Asset Pack writes the map with its own pictures and models as one self-contained asset pack.
- Compile profiles can pack the map before the other steps run, so the game always loads the current copy.
- Shader material slots pack into the asset pack like face materials.

## SDKs

- **New Feature:** Update checks at launch and from Help > Check for Updates, with one click Install and restart for MapCraft and Update SDKs for installed SDKs.
- Updating an SDK no longer reopens its settings window.
- SDK check warns when a program or wine is not installed on this computer instead of failing the SDK.
- Compiles stop with an error naming any unknown or unset path variable instead of expanding it to nothing.
- Preferences adds a setting to turn off update checks at launch.

## Godot Addon

- Imports read the map's custom asset pack, including its pictures, models and PBR materials.
- World sky shaders become the environment's sky and brush shaders draw their faces, shared between brushes with matching shaders.
- Prefabs load only from inside the project, and map names stay inside the project folder.
- Brush collision is one sided like Source brushes, so surf ramps no longer catch players crossing a ridge.
