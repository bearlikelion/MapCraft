# MapCraft Update

## SDK Conversion

- **New Feature:** Convert in File > Switch SDK turns a map's entities and materials into another SDK's, as one undo step.
- Importing a Counter-Strike: Source BSP or VMF into a SurfsUp map converts it on the way in: teleports, boosters, kill boxes and spawns become SurfsUp zones and destinations, and walls join the world.
- SurfsUp maps convert to Counter-Strike: Source with start and finish triggers named the way surf timers find them.
- Converted maps keep the textures of the SDK they came from.
- Counter-Strike: Source compiles pack textures the game does not ship into the BSP, so converted SurfsUp maps look the same in game.

## Source BSP Import

- Imported BSPs follow SurfsUp's own layout: World, Skybox3D, BrushCollision, LadderCollision, SourceEntities, Props and SourceEnvironment.
- Clip, nodraw and ladder brushes start hidden, so the playable map is in view.
- One spawn point stands in for Counter-Strike's spawns, where SurfsUp spawns the player.
- Brushes and entities in the 3D skybox get their own group.

## Views

- **New Feature:** Show Nodraw in the View menu hides nodraw faces in the 3D view, so compiled maps no longer wall off their insides.
- The 3D view shows the fly speed while the mouse wheel changes it.

## Godot

- Layers and groups come into Godot as Node3D nodes, keeping the map's hierarchy.
- **New Feature:** Save as Editable Scene in the FileSystem dock turns a map or pack into a scene you can rearrange, script and relight.
- The player start stays at the scene's root wherever it sits in the map's groups.

## Other

- **New Feature:** Help > Changelog opens the changelog on the MapCraft website.
- Plugins need rebuilding for plugin API 0.5.0.
