# MapCraft Update

## Generators

- A new Surf Ramp, Bhop Platforms or other generator starts with the settings of the one last placed, changed or resized, also after a restart.
- **New Feature:** Set as default keeps a generator's current settings as your own defaults, Use default puts them back and Forget default returns to the plugin's own.
- The Plugins menu window opens with the last used settings.

## SurfsUp

- The default Surf Ramp is 416 wide and 512 tall, about 51 degrees, and fits a grid of 32.
