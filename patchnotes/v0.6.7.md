# MapCraft Update

## Lighting

- **New Feature:** Phong shading smooths the shading where brush faces meet, set per brush entity or for the whole world with an angle limit, in the Lit view, baked lighting and Godot.

## Editing

- **New Feature:** Merge Faces makes a new brush spanning two picked faces.
- **New Feature:** Fix Z-Fighting stops faces covered by other brushes' faces on the same plane from drawing and picks the ones that only partly overlap.
- Color fields accept only numbers.
- A face touching another brush no longer flickers in the 3D view when seen from inside that brush.

## SurfsUp

- Blocks and other drawn shapes start as tools/skip, so only painted faces draw.

## SDKs

- An SDK can name the material new shapes are made of and the material hidden faces get.
