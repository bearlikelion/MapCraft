# MapCraft Update

## Editing

- **New Feature:** The History tab lists your latest edits, each with arrows that undo or redo that one edit and keep everything done since.
- **New Feature:** Edit > Undo in Selection, on Ctrl+Alt+Z, undoes the last edit to the selected objects only.
- Edit > Redo in Selection, on Ctrl+Alt+Shift+Z or Ctrl+Alt+Y, brings it back.
- Ctrl+Y redoes, alongside Ctrl+Shift+Z.
- An action takes more than one shortcut, with commas between them in Preferences.
- History steps in Preferences sets how many edits the History tab lists.
- Clicking a surf ramp or other generated object selects the whole object instead of one of its brushes.
- A moved surf ramp or other generated object stays where it was moved when its values are edited, instead of jumping back to where it was placed.
- Double clicking a layer's name in the scene tree, or pressing F2 on a selected layer or group, renames it in place.

## Lighting

- **New Feature:** Dirt on the World darkens corners and crevices in baked lighting, with its own depth, scale, gain and angle.
- **New Feature:** Lightmap samples bakes 2 x 2 or 4 x 4 samples per luxel for smoother shadow edges.
- **New Feature:** Lightmap softening blurs baked shadow edges.
- Lightmap bias sets how far off a surface baked light is measured, to clear dark specks or stop leaks through thin brushes.
- Bounce color sets how much of a surface's color tints the light it bounces.
- Minimum light exclude names materials that take no minimum light.
- Brushes standing on a face no longer leave a dark fringe around them in baked lighting.
- Changing a material's emission marks the baked lighting out of date.
- Command line bakes take the samples and softening settings.

## Shaders

- **New Feature:** Tools > Shader > Select Brushes With Same Shader, and Select same shader in the inspector, select every brush sharing a shader.
- Add Shader gives brushes the shader the rest of the selection already shares, so one shader goes onto many brushes.
- Script edits, Import .gdshader and Remove shader reach every selected brush with the same shader.
- Shader Parameters shows for several brushes that share a shader, sets a parameter on all of them, and marks values that differ as mixed.
- Copy and paste, Duplicate and Paste Special keep a brush's shader and its parameters.

## Other

- Edit > Open Data Folder shows MapCraft's data folder in the file manager.
- Lightmap scale and the sun's direction have clearer descriptions in the inspector.
