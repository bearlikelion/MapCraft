# MapCraft Update

## SDKs

- **New Feature:** Include Godot entities in the SDK Manager's Create tab starts an SDK for your own Godot game.
- Godot SDKs come with light_environment, light, light_spot, prop_static, func_detail, func_illusionary and info_player_start, ready for the MapCraft Godot addon.
- Godot SDKs bake lighting, place models from the Godot project, and send maps to it from the Run menu.
- Godot SDKs include the entity map the Godot addon needs, with setup steps in their README.

## Godot

- Materials with emission that gives off no light now take anti-tiling and blending in the game.
