Tutorial

Never made a map? Build a room you can walk around in, one step at a time, in about 20 minutes.

  1. Start a new map
  2. Find your way around
  3. Set the grid
  4. Draw a block
  5. Make it taller
  6. Hollow it into a room
  7. Look inside
  8. Paint it
  9. Add a spawn point
  10. Add a sun and see it lit
  11. Save
  12. Check for problems
  13. Play it
