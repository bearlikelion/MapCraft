A few keys do most of the work.
Learn these first; [Keyboard shortcuts](shortcuts.md) lists every one and shows how to change them.

## Pick a tool

The tools sit under your left hand.

| Key | Tool |
|---|---|
| `Q` | Select |
| `W` | Move |
| `E` | Extrude |
| `R` | Rotate |
| `T` | Scale |
| `B` | Block |
| `N` | Entity |
| `C` | Clip |
| `V` | Vertex |
| `Shift+F` | Face |
| `D` | Sculpt |
| `P` | Path |

`Escape` goes back to Select from any tool.

## Get around

| Keys | Does |
|---|---|
| `Space` | Fills the window with the view under the pointer; press it again to go back |
| `F` | Frames the selection |
| `Home` | Frames the whole map |
| `Z` | Next render mode: Textured, Flat, Wireframe, Lit |
| Scroll | Zooms a 2D view |
| Middle or right drag | Pans a 2D view |
| Right drag + `W` `A` `S` `D` | Flies the 3D camera; `Q` and `E` go down and up, `Shift` goes faster |
| Right drag + scroll | Changes how fast you fly |

## Select and edit

| Keys | Does |
|---|---|
| `Ctrl+Z`, `Ctrl+Shift+Z` | Undo, redo |
| `Ctrl+D` | Duplicates the selection |
| `Delete` | Deletes the selection |
| `Ctrl+A`, `Ctrl+Shift+A` | Selects everything, or nothing |
| `Alt+1`, `Alt+2`, `Alt+3` | Clicks pick whole groups, objects, or single brushes |
| Arrow keys | Nudge the selection one grid step in the 2D view under the pointer |
| `Ctrl+G`, `Ctrl+U` | Group, ungroup |
| `H`, `I`, `U` | Hide the selection, show only the selection, show everything |

## Grid and snapping

| Keys | Does |
|---|---|
| `[`, `]` | Halves or doubles the grid |
| `Shift+W` | Turns snapping to the grid on or off |
| `Shift+Q` | Turns snapping to brush corners on or off |

## Save and play

| Keys | Does |
|---|---|
| `Ctrl+S` | Saves the map |
| `F9` | Runs the last Run profile, such as playing the map in your game |
| `F1` | Lists every shortcut, with a search box |

## Coming from Hammer or TrenchBroom

These are MapCraft's own keys.
To use the keys your hands already know, open **Edit > Preferences** (`Ctrl+Comma`) and pick the **Hammer** or **TrenchBroom** preset under **Shortcuts**.
[Keyboard shortcuts](shortcuts.md#change-a-shortcut) shows how.
